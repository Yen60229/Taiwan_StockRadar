🔍 核心篩選 SQL
-- 篩選日均量 ≥ 2000 且籌碼集中度 ≥ 40% 的股票
SELECT
    s.code, s.name, s.industry,
    dq.close, dq.avg_vol_20d,
    cc.conc_ratio,
    SUM(if_.total_net) AS inst_net_5d
FROM stocks s
JOIN daily_quotes dq
    ON dq.stock_code = s.code
    AND dq.trade_date = CURRENT_DATE
JOIN chip_concentration cc
    ON cc.stock_code = s.code
    AND cc.week_date = (
        SELECT MAX(week_date) FROM chip_concentration
    )
LEFT JOIN institutional_flow if_
    ON if_.stock_code = s.code
    AND if_.trade_date >= CURRENT_DATE - INTERVAL '5 days'
WHERE
    dq.avg_vol_20d >= 2000      -- 日均量條件
    AND cc.conc_ratio >= 40.0   -- 籌碼集中度條件
GROUP BY s.code, s.name, s.industry, dq.close, dq.avg_vol_20d, cc.conc_ratio
ORDER BY cc.conc_ratio DESC;

Step 1 — 抓取 TWSE / TPEX 最新行情
打 TWSE STOCK_DAY_ALL + TPEX daily close API，取得所有股票當週最後一個交易日行情，計算 20 日均量，先過濾 vol ≥ 2000 的候選股
# scraper/twse_scraper.py import httpx, pandas as pd async def fetch_twse_all(): url = "https://openapi.twse.com.tw/v1/exchangeReport/STOCK_DAY_ALL" async with httpx.AsyncClient() as client: r = await client.get(url, timeout=30) df = pd.DataFrame(r.json()) df['volume_k'] = pd.to_numeric(df['TradeVolume'], errors='coerce') / 1000 return df[df['volume_k'] >= 2000] # 初步過濾
3
Step 2 — 爬取集保籌碼集中度
只針對 Step 1 過濾後的候選股（約 200~400 檔）逐一 POST 集保查詢，解析 HTML table，計算 400 張以上人數比例。每次請求間隔 1.5 秒
# scraper/tdcc_scraper.py async def fetch_chip_concentration(stock_code: str, week_date: str) -> float: url = "https://www.tdcc.com.tw/portal/zh/smWeb/qryStock" payload = {"scaDates": week_date, "SqlMethod": "StockNo", "StockNo": stock_code, "REQ_TYPE": ""} async with httpx.AsyncClient() as client: r = await client.post(url, data=payload, timeout=20) soup = BeautifulSoup(r.text, "html.parser") rows = soup.select("table.hasBorder tr") # 解析持股級距：400張以上 = 第13~16行 holders_400up = sum_holders_above_400(rows) total = get_total_holders(rows) return round(holders_400up / total * 100, 2)
4
Step 3 — 合併資料、寫入 PostgreSQL
用 pandas merge 對齊股票代號，寫入 daily_quotes + chip_concentration。使用 upsert（ON CONFLICT DO UPDATE）避免重複
# pipeline/data_pipeline.py from sqlalchemy import text async def upsert_daily_quotes(df, conn): for _, row in df.iterrows(): await conn.execute(text(""" INSERT INTO daily_quotes (stock_code, trade_date, close, volume, avg_vol_20d) VALUES (:code, :date, :close, :vol, :avg) ON CONFLICT (stock_code, trade_date) DO UPDATE SET close=EXCLUDED.close, avg_vol_20d=EXCLUDED.avg_vol_20d """), row.to_dict())

# StockRadar 週報任務

## 目標
每週六/週日自動執行台灣股市篩選，產出符合條件股票清單並寄送 Email 通知。

## 篩選條件
- 日均成交量（近20交易日）>= 2,000 張
- 籌碼集中度（400張以上持股人數比例）>= 40%
- 同時符合上市（TWSE）與上櫃（TPEX）股票

## 執行步驟
1. 執行 python scraper/twse_scraper.py 抓取最新行情
2. 執行 python scraper/tpex_scraper.py 抓取上櫃行情
3. 執行 python scraper/tdcc_scraper.py --candidates 只抓候選股集保資料
4. 執行 python pipeline/merge_and_filter.py 合併篩選
5. 執行 python notifier/send_email.py 發送 Resend Email

## 錯誤處理
- 若任何步驟失敗，請讀取錯誤訊息，嘗試修正後重新執行（最多重試3次）
- 若集保網站 HTML 結構改變，請自行調試 parser 邏輯
- 若連續失敗，寄送錯誤通知信給 admin@stockradar.tw

## 完成標準
Email 發送成功，並在 logs/run_YYYYMMDD.log 記錄執行結果
